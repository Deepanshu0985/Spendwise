# Design System

## Principles
Consistent spacing, clear hierarchy, readable financial numbers, explicit states and confirmation for destructive actions.

## Components
Button, input, select, date picker, modal, drawer, table, pagination, tabs, badge, toast, card, empty state, skeleton, confirmation dialog.

## States
Default, hover, focus, disabled, loading, error and success.

## Typography
Use a readable sans-serif hierarchy for display, headings, body, captions and numeric emphasis.

## Financial Formatting
Use locale-aware currency formatting. Preserve backend precision. UI rounding is display-only and never changes calculations.
