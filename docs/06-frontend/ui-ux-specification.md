# UI/UX Specification

## Navigation
Dashboard, Transactions, Accounts, Statements, Budgets, Goals, Recurring, AI Assistant, Settings.

## Dashboard
Period selector; income; expenses; savings; savings rate; category breakdown; trend; top merchants; budgets; recurring payments; AI insights.

## Transactions
Quick Add, search, filters, sorting, pagination and inline editing.

## Statement Review
Table columns: include, date, description, amount, type, merchant, category, confidence, duplicate flag and edit.

## AI Assistant
Chat, suggested questions, clear period/context, grounded responses.

## UX Principles
Fast entry, low cognitive load, responsive layout, accessible controls, clear loading/error/empty states.

## Accessibility
Keyboard navigation, semantic headings, labels, readable tables and sufficient contrast.
